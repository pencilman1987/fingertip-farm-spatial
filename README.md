# 指尖农场·空间版

《指尖农场》的 PICO OS 6 / Spatial SDK 版本。项目使用平面 `DefaultWindowContainer` 运行在 Shared Space，可与其他应用窗口并存，并通过手势或手柄指针操作农田与空间键盘。

核心循环是“新建日记并种下关联作物 → 自动保存写作 → 字符里程碑与完成记录推动作物成长 → 回农场收获 → 生成可重新打开的记忆卡”。系统文本输入、空间 QWERTY 键盘、常用中文词、专注计时和本地持久化继续保留。

视觉设计直接继承原始 Web 包：手绘天空草地、暖木建筑、等距棕色土壤键帽、绿色成长键帽、蓝色鱼塘以及黑绿 CRT 工作间。原始远程插画已转为本地 Android 资源，运行时不依赖外部图片服务。

## 已实现

- 45 块键帽农田 + 2 座鱼塘
- 点击播种/投苗、照料、成熟与收获
- 金币收益、品种购买、仓库选择
- 伙伴招募与自动能力：小羊沿键盘巡逻收获、猫咪定时钓鱼并播放抛竿动画、小猪每日问题、羊驼季节贴纸
- 多篇日期日记、自动保存、标题与正文重编辑
- 每篇日记独占一株关联作物，完成后收获为可回看的记忆卡
- 写作、日期归档、记忆卡三种工坊内容状态；空间键盘默认折叠
- 25 分钟专注计时
- SharedPreferences 本地存档
- SpatialUI 悬停、点击指示和手柄震动

新存档从 80G 开始；WPM 只显示即时输入速度，不再提供成长倍率。已有存档金币不会被重置。
